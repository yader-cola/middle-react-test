# Магазин на React + TypeScript

Проект — интернет-магазин, реализованный на React с использованием TypeScript. Включает навигацию по категориям и корзину, отображаемую в Sidebar.

## Основные характеристики
- Использует React Router для навигации между страницами без перезагрузки
- Страницы для главной и категорий товаров
- Корзина реализована как модальное окно Sidebar
- Использует Vite для быстрой сборки и разработки

## Как запустить
1. Установите зависимости:
npm install
2. Запустите проект:
npm run dev
3. Откройте браузер и перейдите по адресу, который появится в консоли (обычно http://localhost:5173)
